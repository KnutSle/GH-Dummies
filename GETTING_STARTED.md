# Getting Started with GitHub

Welcome! This repository is designed to help you learn GitHub basics.

## What is GitHub?

GitHub is a platform for version control and collaboration. It lets you and others work together on projects from anywhere.

## Key Concepts

### Repository (Repo)
A repository contains all of your project's files and each file's revision history.

### Branch
A branch is a parallel version of your repository. It allows you to work on changes without affecting the main codebase.

### Commit
A commit is a saved change to your repository. Each commit has a message describing what changed.

### Pull Request (PR)
A pull request is a proposal to merge your changes into another branch. It allows others to review your code.

### Issue
An issue is a way to track bugs, enhancements, or other requests for your project.

## Quick Start

1. **Fork this repository** (optional for learning)
2. **Clone** your fork or this repository
3. **Create a branch** for your changes
4. **Make changes** to files (try editing `hello.py`)
5. **Commit** your changes
6. **Push** your branch to GitHub
7. **Open a Pull Request** to propose your changes

## Try It Yourself

1. Run the example program:
   ```bash
   python hello.py
   ```

2. Modify the `hello.py` file - change the greeting or add a new function

3. See what changed:
   ```bash
   git status
   git diff
   ```

4. Commit your changes:
   ```bash
   git add hello.py
   git commit -m "Updated greeting message"
   ```
