# GH-Dummies

Welcome to the GitHub for Dummies course repository! 🎓

This repository is designed to help you learn GitHub basics through hands-on practice.

## 📚 What's Inside

- **hello.py** - A simple Python program to practice making changes
- **GETTING_STARTED.md** - Introduction to GitHub concepts
- **CONTRIBUTING.md** - Step-by-step guide for Git and GitHub workflows

## 🚀 Quick Start

1. Clone this repository
2. Read [GETTING_STARTED.md](GETTING_STARTED.md) to learn GitHub basics
3. Try running the example program: `python hello.py`
4. Follow [CONTRIBUTING.md](CONTRIBUTING.md) to practice the GitHub workflow

## 🎯 Learning Goals

By using this repository, you'll learn:
- How to clone and fork repositories
- Creating branches and making commits
- Using git commands (status, add, commit, push)
- Opening and managing pull requests
- Working with issues
- Collaborating with others on GitHub
